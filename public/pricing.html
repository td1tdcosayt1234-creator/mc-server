FAQ / common q

Common questions.

Actual hosting cost?

No — the panel is self-hosted. The MC server runs on your machine. If friends join over the internet → set up playit.gg or a Cloudflare tunnel (in docs).

Do I need to install Java?

No — the panel auto-downloads the right JRE (17/21/8) per version into the runtime folder. It decides for you when you pick a version on the Create page.

How many servers can run?

As many as your RAM allows. 4-5 servers run comfortably on a 16GB machine.

When does beta end?

After beta, Starter stays free; Pro suggested $5/mo, Team $12/mo. Self-host means everything is yours — no cloud bill.
