01 / Quick start

5 minute e chalu.

Node.js 18+ required (Node 22 recommended). One line does it:

# clone + install + chalau git clone https://github.com/td1tdcosayt1234-creator/mc-server.git cd mc-server npm install node server.js

Now open http://localhost:3000 — the first signup becomes admin. Create a server from the Create page: name + platform + version + RAM → Create + Download (auto jar)

Tip: the server folder lives at servers/<id> — full file access inside the panel. Git ignores the folder.

03 / Login & roles

Accounts, roles.

Auth is fully local — db.json. Passwords hash with scrypt + random salt. Session = 7 days (remember-me 30), HttpOnly cookie.

  • First signup = admin (self-host panel er sensible default)
  • admin — all servers, user management, requireLogin toggle
  • user — nijer create kora server only (owner: 403 guard)
  • From the Admin page: "Login required" toggle — off means open access (the old style)
04 / Auto Java

Java — zero setup.

Per-version mapping → the panel ensures the JRE itself:

// net Java mapping (lib/java.js) MC 1.20.5 – 1.21.x → Java 21 (Temurin JRE auto-download) MC 1.17.0 – 1.20.4 → Java 17 MC ≤ 1.16.5 → Java 8

Runtime folder: runtime/java-<major> (gitignored). If system java matches, that one is used — no download. Download progress shows in the live console.

05 / Console & files

Real terminal, real file manager.

Console page: SSE line-by-line stream, command input history (↑↓), power buttons (Start/Restart/Stop/Kill), CPU/RAM live bars. Files page: explorer + editor (Ctrl+S save), upload/download, rename/delete, khujar filter. Startup tab → RAM ti Java args; Settings tab → server.properties form + raw mode.

Auto-restart: on crash it reboots itself after 5s (skips on port-conflict, blocks crash-loops).
06 / Backups

Auto backup + Drive.

Every BACKUP_MINUTES (default 50) minutes a zip backup is taken: backups/<server>/. With a Google Drive service account it also uploads there. One-click Restore from the Backup tab (stops the server, full overwrite) + download.

07 / Config (.env)

Environment vars.

PORT=3000 SERVERS_DIR=./servers BACKUPS_DIR=./backups BACKUP_MINUTES=50 FIREBASE_SERVICE_ACCOUNT=./serviceAccount.json # khali = local db.json DRIVE_FOLDER_ID= # empty = local backups

db.json stores users + servers + settings (local mode). With Firebase it stores in Firestore — panel auth currently runs in local mode.

09 / Bondhu ra join

Connect paths.

  • Same PC: localhost:25565
  • LAN/Tailscale: the panel's Network tab shows LAN IP + port (Tailscale works even behind CGNAT)
  • Internet: router port-forward (TCP+UDP) or a playit.gg tunnel (free, MC friendly) — set it up and give friends the tunnel address
  • Multi-port: duita server duita port (Settings tab e server-port change)
10 / Troubleshoot

Common issues & fixes.

  • "port already used" → another server or an orphan java holds the port; stop that server or change the port in Settings
  • Crash-loop guard → auto-restart pauses itself — read the console log
  • EULA → "eula.txt accept" button in the Startup tab
  • NeoForge installer fail? → check the network; create again for a fresh install
  • Restart panel → close the node window: Ctrl+C → node server.js (backups + servers folders stay untouched)
