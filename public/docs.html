01 / Quick start

5 minute e chalu.

Node.js 18+ lagbe (Node 22 recommended). Ek line ei kaj:

# clone + install + chalau git clone https://github.com/td1tdcosayt1234-creator/mc-server.git cd mc-server npm install node server.js

Ekhon http://localhost:3000 — first signup korle oi account admin. Create page theke server create koro: name + platform + version + RAM → Create + Download (auto jar)

Tip: server folder servers/<id> e thakbe — full file access panel ei. Git nijer folder ignore kore.

03 / Login & roles

Accounts, roles.

Auth ekdom local — db.json e. Password scrypt + random salt hash hoy. Session = 7 din, HttpOnly cookie.

  • First signup = admin (self-host panel er sensible default)
  • admin — sob server, user manage, requireLogin toggle
  • user — nijer create kora server only (owner: 403 guard)
  • Admin page theke "Login required" toggle — off korle khola access (giya style)
04 / Auto Java

Java niye tension nai.

Version onujayi mapping → panel nijei JRE ensure kore:

// net Java mapping (lib/java.js) MC 1.20.5 – 1.21.x → Java 21 (Temurin JRE auto-download) MC 1.17.0 – 1.20.4 → Java 17 MC ≤ 1.16.5 → Java 8

Runtime folder: runtime/java-<major> (gitignored). System java match korle oi ta — no download. Download progress live console e dekhbo.

05 / Console & files

Real terminal, real file manager.

Console page: SSE line-by-line stream, command input history (↑↓), power buttons (Start/Restart/Stop/Kill), CPU/RAM live bars. Files page: explorer + editor (Ctrl+S save), upload/download, rename/delete, khujar filter. Startup tab → RAM ti Java args; Settings tab → server.properties form + raw mode.

Auto-restart: crash korle 5s por nijei bose (port-conflict thakle skip, crash-loop block).
06 / Backups

Auto backup + Drive.

Prottek BACKUP_MINUTES (default 50) minute por por zip backup: backups/<server>/. Google Drive service account thakle oikhane o jai. Backup tab theke one-click Restore (server stop kore full overwrite) + download.

07 / Config (.env)

Environment vars.

PORT=3000 SERVERS_DIR=./servers BACKUPS_DIR=./backups BACKUP_MINUTES=50 FIREBASE_SERVICE_ACCOUNT=./serviceAccount.json # khali = local db.json DRIVE_FOLDER_ID= # khali = local backups

db.json e users + servers + settings rakha-hoi (local mode). Firebase thakle Firestore — panel apatoto auth local mode e.

08 / API

REST endpoints.

GET /api/versions # 9 platform er version list GET /api/info # java + runtime + ips GET /api/servers # list (+stats) POST /api/servers # create {name,type,version,ram} POST /api/servers/:id/start|stop|restart|kill GET /api/servers/:id/logs?tail= | /console (SSE) | /files?dir= POST /api/servers/:id/command #{cmd:'say hi'} GET/POST /api/servers/:id/properties POST /api/servers/:id/backup #+ /backups, /backups/:n/restore|download GET /api/servers/:id/plugins # installed plugins+mods list GET /api/servers/:id/plugins/search # 🧩 Market (Modrinth) ?q=&kind=plugin|mod POST /api/servers/:id/plugins/install #{slug,kind} → jar auto download POST /api/servers/:id/plugins/delete #{file,folder} POST /api/auth/signup|login|logout, GET /api/auth/me DELETE /api/servers/:id # admin/owner full delete
09 / Bondhu ra join

Connect paths.

  • Same PC: localhost:25565
  • LAN/Tailscale: panel er Network tab e LAN IP + port dekhabe (Tailscale install = CGNAT e o kaj kore)
  • Internet: router port-forward (TCP+UDP) ba playit.gg tunnel (free, MC friendly) — bandho kore bondhu ke tunnel address dao
  • Multi-port: duita server duita port (Settings tab e server-port change)
10 / Troubleshoot

Common issues & fixes.

  • "port already used" → onno server ba orphan java oi port e; oi server stop koro ba Settings e port change
  • Crash-loop guard → auto-restart thamiye dekhabe — console log poro
  • EULA → Startup tab e "eula.txt accept" button
  • NeoForge installer fail? → network check; abar create korle fresh install
  • Restart panel → node mesh niye: Ctrl+C → node server.js (backups + servers folder thik thakbe)
